# ai.sergiobertolini.com

Sito personale di **Sergio Bertolini** — consulente e formatore di AI generativa per aziende, scuole e professionisti.

🌐 Live: [ai.sergiobertolini.com](https://ai.sergiobertolini.com)

## Cosa contiene questo repository

Solo i file pubblicati del sito: pagine HTML e asset statici (immagini). Non è il repository di lavoro — appunti, bozze e note di progetto restano in un repository privato separato.

```
├── index.html                    Home
├── chi-sono.html                 Chi sono
├── ai-per-aziende.html           Per la tua azienda
├── formazione-ai-scuole.html     Formazione AI per la scuola
├── percorsi-individuali.html     Percorsi individuali (One2One)
├── collaborazioni.html           Collaborazioni (formatore AI a contratto)
├── dove-mi-hanno-visto.html      Public speaking / interventi
├── contatti.html                 Contatti
├── assets/                       Immagini, foto, loghi
├── CNAME                         Dominio personalizzato per GitHub Pages
└── .nojekyll                     Disabilita l'elaborazione Jekyll
```

Ogni pagina è un file HTML autonomo, con il proprio CSS inline (nessun foglio di stile condiviso tra le pagine).

## Hosting

Il sito è pubblicato tramite **GitHub Pages** direttamente da questo repository (branch `main`, root). Il dominio `ai.sergiobertolini.com` è collegato via record `CNAME` DNS e certificato HTTPS gestito automaticamente da GitHub.
